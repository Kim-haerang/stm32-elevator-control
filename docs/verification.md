# 확인 범위와 후속 검증

## 문서 작성 시 확인

- 최종 ZIP의 C 코드, `.ioc`, 타이머 초기화와 IRQ 핸들러를 비교했습니다.
- PPT에 기재된 TIM2 2ms·TIM5 1ms·TIM4 1ms와 최종 소스 설정이 일치합니다.
- 비상 디바운스, 다음 감지 층 정지 예약, 로비 조도 2700/1200, 온도 30°C 이상과 조도 2600 초과 조건을 확인했습니다.
- 이전 코드와 최종 코드의 차이는 트러블슈팅에 활용하되, 개선율이나 실제 시간 측정값을 만들지 않았습니다.

## 아직 검증하지 않은 항목

- 깨끗한 STM32CubeIDE 환경에서 가져오기·빌드·다운로드
- 실제 보드와 모형의 배선, 전원 인가 초기 위치, 전체 시나리오 재실행
- 시연 영상의 장면별 판독과 비로그인 링크 접근
- 원 개발 IDE 버전과 PC GUI 실행 환경

## 보드 검증 시 기록할 항목

| 시나리오 | 확인할 동작 | 결과 |
| --- | --- | --- |
| 1↔2↔3층 이동 | 목표 층 감지 시 정지, 현재 층 표시 | 미실행 |
| 1→3층 중 2층 전·후 비상 | 다음 감지 층에서 정지 | 미실행 |
| 3→1층 중 2층 전·후 비상 | 하강 방향 유지 및 다음 층 정지 | 미실행 |
| 이동 중 비상 입력 해제 | 예약된 정지 처리 후 상태 전환 | 미실행 |
| 로비 접근·차단·이탈 | 거리 조건, 히스테리시스, 재호출 | 미실행 |
| 온도·조도 조건 조합 | 두 조건 동시 충족과 해제 | 미실행 |
| UART 제어와 상태 조회 | 명령 수신·응답과 실제 모형 상태 대응 | 미실행 |

## 현재 코드의 제약과 개선 후보

다음 항목은 수정 완료 내역이 아니며 원본 코드를 보존한 채 기록한 사항입니다.

- 초기 `current_floor`가 1층으로 설정되며 자동 원점 탐색은 없습니다.
- 이동 중 층 센서가 검출되지 않을 때의 이동 타임아웃은 없습니다.
- UART 명령 변수의 유지·소비 정책, 잘못된 payload 처리, 반복 명령 동작은 추가 확인이 필요합니다.
- UART 응답의 블로킹 송신과 TIM2·TIM5·USART2의 동일 NVIC 우선순위가 실제 지연에 미치는 영향을 측정해야 합니다.
- 일부 include 경로의 `stepMotor`와 실제 `StepMotor` 디렉터리 표기가 달라 대소문자 구분 환경의 빌드 이식성을 확인해야 합니다.
- 타이머 ISR 설정만으로 비상 응답 상한이나 안전성을 보장한다고 주장하지 않습니다.
