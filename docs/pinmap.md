# 핀 연결

발표자료의 핀맵과 최종 코드의 주요 GPIO·주변장치 설정을 기준으로 정리했습니다. 실제 모형의 배선 확인을 대신하지 않습니다.

| 구성 | MCU 핀 | 용도 |
| --- | --- | --- |
| 1·2·3층 센서 | PA1 / PA4 / PB0 | ADC 채널 1 / 4 / 8 |
| 로비 조도 | PC2 | ADC 채널 12 |
| 화재 판단용 조도 | PA0 | ADC 채널 0 |
| 1·2·3층 버튼 | PC0 / PC1 / PC3 | 층 요청 |
| 비상 버튼 | PB13 | 눌림·해제 입력 |
| HC-SR04 | PC5 / PC6 | TRIG / ECHO |
| 접근·복귀 LED | PB15 / PB14 | 로비 상태 표시 |
| 스텝 모터 드라이버 | PA12 / PA11 / PB12 / PB2 | 위상 출력 순서 |
| LCD·DS3231 | PB8 / PB9 | I2C1 SCL / SDA 공용 |
| DHT11 | PC8 | 온습도 데이터 |
| 부저 | PB1 | TIM3 CH4 PWM |
| USART2 | PA2 / PA3 | TX / RX, 115200 8N1 |
| FND SEG | PA6 PA9 PB5 PB10 PA8 PA7 PB3 PB4 | 발표자료에 기재된 순서 |
| FND DIG | PA5 PB6 PC7 PA10 | 발표자료에 기재된 순서 |

ADC DMA 버퍼는 층 센서 3개, 로비 조도, 화재 판단용 조도 순서입니다. 센서 종류·설치 위치에 따른 ADC 임계값은 물리량으로 보정된 수치가 아닙니다.
